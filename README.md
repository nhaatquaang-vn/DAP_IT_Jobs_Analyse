# Simple Interest Calculator

A utility that calculates simple interest for a given principal amount, interest rate, and time period.

## Description
Simple interest is calculated with the following formula:
Simple Interest = (Principal * Rate * Time) / 100

This project contains a bash script that takes the following inputs to compute the interest:
* **Principal:** The initial amount of money borrowed or invested.
* **Rate of interest:** The annual interest rate (in percentage).
* **Time period:** The time the money is invested or borrowed for, in years.

## Usage
Run the `simple-interest.sh` script and follow the prompts to enter the principal, rate, and time.
